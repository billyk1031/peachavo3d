Working with PeachAvo3D

Starting with the real-world question.

What kinds of projects can PeachAvo3D help with?

We work on replacement and repair parts, organisers, mounts, brackets, early product prototypes, small runs, decorative objects, original figures and personal creative projects. Every request is reviewed individually.

Do I need a finished 3D model before getting in touch?

No. A photo, rough sketch, measurements, existing object or clear description can be enough to start. We can assess what is needed to turn the idea into a printable design.

What should I include in an enquiry?

Send what you have: a photo, sketch, measurements, intended use, quantity and any preferred timing. It is also useful to say what needs to fit, move, hold or simply look a certain way.

How is a 3D design and printing project quoted?

Projects are individually quoted after we understand the design work, material, quantity, finishing and any iteration involved. We do not use fixed packages or assumed turnaround times.

Can you design a replacement part for something broken?

Often, yes. Photos of the broken part and surrounding area, key measurements, how it fitted or moved, and what the replacement needs to do are all useful. Suitability is reviewed case by case.

Do you work with people across the UK?

Yes. We welcome UK-wide enquiries. The first step is simply to email a description, photo, sketch or measurements of the idea.

Understanding 3D design

Turning an idea into a digital object.

What is 3D design?

3D design is the process of creating a digital model with height, width and depth. The model can be used to explore an idea, check proportions, make a prototype or prepare an object for 3D printing.

Can a 3D model be made from a sketch or photo?

A sketch or photo can be a useful starting point, especially when paired with measurements and a description of how the object will be used. More reference usually leads to a more confident design decision.

Why are measurements important for a custom 3D printed part?

Measurements help a custom part fit the object, space or mechanism it is being made for. Dimensions, fixing points, clearances and a reference object or ruler in photos can all help.

Can you help if I have an existing 3D model?

Yes. Send the file with a short note about what you would like to make or change. We can review whether it appears suitable for the intended next step and identify any design work that may still be needed.

Can you help with figures and decorative 3D printed objects?

Yes. We welcome non-functional ideas as well as practical ones, including original figures, display pieces, decorative home objects, gifts and sculptural concepts.

Understanding 3D printing

How a digital model becomes an object.

What is FDM 3D printing?

FDM is a 3D printing method that builds an object layer by layer from plastic filament. It is a flexible starting point for prototypes, practical parts and textured decorative work, and is currently available from PeachAvo3D.

Will a 3D printed object have visible layer lines?

FDM prints are built in layers, so some layer texture may be visible. The result depends on the object shape, chosen material, layer height, orientation and intended finish. These are considered when a project is reviewed.

Can I order just one 3D printed item?

Yes. One-off objects, prototypes and replacement parts are welcome, as are low-volume runs. Quantity is one of the details used to scope and quote a project.

Is SLA or resin 3D printing available?

SLA or resin 3D printing is coming soon. We will be clear about the available and suitable options when reviewing an enquiry.

Is full-colour 3D printing available?

Full-colour 3D printing is coming soon. We can still discuss the creative direction for your project and advise on the currently available options.

Planning a project

Making a useful next decision.

What is the difference between a prototype and a finished product?

A prototype is a physical version used to explore form, fit, function or presentation before the next decision. A finished object may need a different level of material choice, refinement or repeatability, depending on its intended use.

Can you make several versions of an idea?

Yes. Iteration can be useful when testing fit, proportions, practical use or visual direction. The likely number of design and print stages is discussed when a project is scoped.

How long does a custom 3D printing project take?

Timing depends on the design work, required iteration, print size, quantity and finishing. We review each project individually before discussing an appropriate next step and timing.

Can I send confidential or commercially sensitive material?

Please only send material you are comfortable sharing for an initial review. If confidentiality matters to your project, say so in your enquiry before sending detailed files or information.
